== Notes ==
01_SOURCE_CODE.zip: tracked source of commit 5034973; dist/ (in 02) and docs/screenshots (images, in the GitHub repo) are left out.
03_WINDOWS_RELEASE.zip: Setup-1.4.0.exe (installer, NSIS) + Portable-1.4.0.exe + INSTALLATION_GUIDE.md. Not code-signed.
04_ANDROID_RELEASE.zip: IBRAHI8M-EDU-STUDIO-1.4.0.apk (test-key signed, not run on a device) + its source. No AAB.
05_IOS_SOURCE.zip: Xcode project source (Capacitor 6). No IPA: needs macOS/Xcode.
06_ORIGINAL_BACKUP.zip: full source of 1.3.0 (commit bf22665) before this work.
08_COMPLETE_RELEASE_BUNDLE.zip: 01-07 + documents, stored without recompression.
Files above 95 MB are also given as numbered parts (.001, .002 …) with a join-*.bat that rebuilds them (copy /b); WinRAR/7-Zip also open the .001 directly.
