# IBRAHI8M 🤖 EDU STUDIO

**Create. Teach. Inspire.** — استوديو عربي لتصميم المحتوى التعليمي الرقمي، يعمل دون إنترنت.

الحالة الحالية: **المرحلة 5 — استوديو التصميم** (الإصدار 0.6.0)، فوق المراحل 0 إلى 4.

- طريقة التشغيل والحفظ على الكمبيوتر والجوال: [`INSTALL.md`](INSTALL.md)
- ما اختُبر وما لم يُختبر: [`TEST-REPORT.md`](TEST-REPORT.md)

## تطبيق واحد لكل الأجهزة

| الجهاز | الواجهة | طريقة التشغيل |
| --- | --- | --- |
| الكمبيوتر | شريط جانبي كامل، استوديو تأليف | تطبيق سطح المكتب (يعمل دون اتصال من أول تشغيل) أو PWA من المتصفح |
| الجهاز اللوحي | شريط جانبي مختصر بالأيقونات | PWA من المتصفح |
| الجوال | شريط علوي وتنقل سفلي، صفحة «المزيد» لكل الوحدات | PWA مثبّت على الشاشة الرئيسية |

لكل جهاز قاعدة بيانات محلية مستقلة (IndexedDB). **لا توجد مزامنة تلقائية**؛ نقل البيانات بين الأجهزة سيكون بملف تصدير واستيراد (المرحلة 6).

## التشغيل للمطور

```bash
npm install
npm run brand        # يولّد الصور والأيقونات من brand-src/
npm run dev          # خادم تطوير (دون Service Worker)
npm run build        # بناء + فحص الروابط الخارجية (يفشل عند أي رابط خارجي)
npm run preview      # معاينة البناء على http://localhost:4173
npm test             # اختبارات الوحدات
npm run test:e2e     # اختبارات المتصفح على 5 مقاسات أجهزة مع فصل الشبكة
xvfb-run -a npm run test:desktop   # اختبارات تطبيق سطح المكتب (Linux)
node scripts/build-legacy.mjs      # يبني إصدارًا سابقًا من Git لاختبار الترقية (يستدعيه الاختبار تلقائيًا)
npm run desktop      # تشغيل تطبيق سطح المكتب
npm run dist:desktop # حزم Windows وLinux في release/
```

## تثبيت PWA على الجوال

1. انشر مجلد `dist/` على أي استضافة ثابتة تعمل بـ HTTPS (مثل GitHub Pages).
2. افتح الرابط مرة واحدة على الجوال في Chrome (Android) أو Safari (iPhone) وانتظر ظهور «جاهز للعمل دون إنترنت» في لوحة التحكم.
3. أضف التطبيق إلى الشاشة الرئيسية. بعد ذلك يعمل في وضع الطيران.

## البنية

```
src/app         التوجيه، الإعدادات، حالة التشغيل دون اتصال، قائمة التنقل
src/components  الهوية (الشعار والصورة)، الهيكل المتجاوب، شاشة البداية
src/pages       لوحة التحكم، المشاريع، محرر الدرس، المعاينة، منشئ الدروس، الاختبارات، وضع الطالب، النتائج، الإعدادات
src/lesson      نموذج الدرس، بنك أفعال بلوم، الكتل، المواءمة، الوسائط المحلية، الحفظ التلقائي، عرض الطالب
src/quiz        نموذج الاختبار، التصحيح التلقائي، المطابقة النصية المرنة، التحليلات، المحرر، وضع الحل
src/student     وضع الطالب: هوية الطالب، أقسام الدرس، التقدم، الإطار المستقل
src/studio      استوديو التصميم: البطاقات والملخصات وخرائط المفاهيم بصيغة SVG، والتصدير PNG بخطوط مضمّنة
src/db          Dexie/IndexedDB (الإصدار 6)، الإعدادات، المشاريع والدروس، محتوى الدروس والوسائط، الاختبارات والمحاولات، تقدم الطلاب، التصاميم، البحث العربي
src/styles      الخطوط المحلية، رموز الألوان، التنسيق
electron/       غلاف سطح المكتب (بروتوكول app:// ومنع كل طلبات الشبكة)
brand-src/      الصورة الأصلية ومصدر الشعار
scripts/        توليد الهوية، فحص البناء دون اتصال، بناء إصدار سابق لاختبار الترقية
tests/          unit · e2e (المتصفح) · desktop (Electron) · fixtures (صورة وصوت وفيديو للاختبار)
```
