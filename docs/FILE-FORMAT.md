# صيغة ملف ‎.ibm‎ (IBRAHI8M EDU STUDIO)

الإصدار الحالي للصيغة: **formatVersion = 1** — قاعدة البيانات المحلية: **v7** — التطبيق: 0.7.0.

ملف `.ibm` هو أرشيف ZIP عادي (يمكن فتحه بأي برنامج ضغط للفحص)، ويُستخدم لغرضين:

| النوع (`kind`) | ينشئه | يحتوي |
|---|---|---|
| `project` | «تصدير مشروع» | مشروع واحد: دروسه، أهدافه ومحتواه، وسائطه، اختباراته، تصاميمه، وبحسب اختيار المعلم نتائج الطلاب وتقدمهم |
| `backup` | «إنشاء نسخة احتياطية» | كل ما على الجهاز: كل المشاريع والدروس والوسائط والاختبارات والمحاولات والتقدم والتصاميم وعناصر المكتبة والإعدادات |

## محتوى الأرشيف

```
manifest.json        وصف الملف (أول ملف في الأرشيف)
data.json            السجلات كلها
assets/<id>.<ext>    كل ملف وسائط كما هو (بايتات خام، دون إعادة ضغط)
```

### manifest.json

```json
{
  "format": "ibrahi8m-edu",
  "formatVersion": 1,
  "kind": "project",
  "schemaVersion": 7,
  "appVersion": "0.7.0",
  "exportedAt": "2026-10-20T08:00:00.000Z",
  "title": "وحدة الطاقة",
  "counts": { "projects": 1, "lessons": 3, "quizzes": 1, "attempts": 4, "progress": 2,
              "designs": 1, "library": 0, "assets": 2, "assetBytes": 81234 },
  "dataSha256": "<SHA-256 لملف data.json بالضبط، 64 حرفًا ست عشريًا>",
  "includesResults": true
}
```

### data.json

كائن واحد، كل مفتاح فيه مصفوفة سجلات بنفس شكل جداول قاعدة البيانات المحلية:

| المفتاح | المحتوى |
|---|---|
| `projects` | المشاريع (`id`, `title`, `subject`, `grade`, `status`, …) |
| `lessons` | بطاقات الدروس (`id`, `projectId`, `title`, `order`, …) |
| `lessonDocs` | محتوى كل درس: الأهداف (مع مستوى بلوم) والاستراتيجيات وعناصر المحتوى وربطها بالأهداف (`lessonId` مفتاحها) |
| `assets` | وصف الوسائط: `id`, `lessonId`, `kind`, `mime`, `name`, `size`, `createdAt` + `path` (مسارها في الأرشيف) + `sha256` |
| `quizzes` | الاختبارات وأسئلتها وإعداداتها |
| `attempts` | محاولات الطلاب (فارغة إن لم تُضمَّن النتائج؛ محاولات المعاينة لا تُصدَّر أبدًا) |
| `progress` | تقدم الطلاب في الدروس (فارغ إن لم تُضمَّن النتائج) |
| `designs` | تصاميم الاستوديو (بطاقات، ملخص، خريطة مفاهيم) |
| `library` | عناصر المكتبة التي أنشأها المعلم (القوالب المدمجة لا تُصدَّر لأنها جزء من التطبيق) |
| `settings` | الإعدادات (في النسخة الاحتياطية فقط) |

وسائط المكتبة نفسها محفوظة في `assets` بالقيمة `lessonId = "library"`.

## الفحص قبل الاستيراد

لا يُكتب شيء قبل أن يمر الملف بكل هذه الفحوص، بالترتيب:

1. الحجم ≤ 700 م.ب، وتوقيع ZIP صحيح.
2. مجموع الحجم المفكوك المعلن ≤ 900 م.ب (حماية من الأرشيفات المضخّمة).
3. `manifest.json` موجود ومطابق للمخطط، و`format = "ibrahi8m-edu"`.
4. `formatVersion` و`schemaVersion` ليسا أحدث من التطبيق؛ الملف الأحدث يُرفض برسالة «أُنشئ هذا الملف بإصدار أحدث…».
5. بصمة `data.json` تطابق `dataSha256`.
6. كل سجل يطابق مخططه (Zod)، ثم يمر بنفس دوال التطبيع التي يستخدمها التطبيق.
7. لا تكرار في المعرّفات، وكل إشارة سليمة (درس ← مشروع، محتوى ← درس، وسيط ← درس، محاولة ← اختبار…). اختبار أو تصميم يشير إلى درس غير موجود يُفصل عن الدرس بدل رفض الملف.
8. كل وسيط موجود في الأرشيف بحجمه المعلن وبصمته `sha256`.

تحذيرات لا تمنع الاستيراد تُعرض في المعاينة: ملف من إصدار أقدم (يُرقّى تلقائيًا)، أو وسيط يشير إليه المحتوى وهو غير موجود.

## قواعد الكتابة

- المعاينة تعرض محتوى الملف وحالة كل مشروع: جديد، أو موجود بنفس المعرّف، أو يوجد مشروع بنفس العنوان.
- الخيارات لكل مشروع: **إضافة** (جديد)، **تخطي**، **نسخة جديدة** (معرّفات جديدة لكل السجلات وعنوان ينتهي بـ« (نسخة مستوردة)»)، **استبدال** (يحتاج تأكيدًا صريحًا).
- الافتراضي لا يحذف ولا يستبدل شيئًا: المشروع الموجود يُتخطّى أو يُستورد نسخة.
- النسخة الاحتياطية تُدمج افتراضيًا؛ «استبدال كل البيانات» يحتاج إقرارًا وتأكيدًا، مع خيار إنشاء نسخة احتياطية من الجهاز أولًا.
- عناصر المكتبة تُضاف إن لم تكن موجودة، ولا تُكرَّر.
- الإعدادات لا تُستعاد إلا إذا اختار المعلم ذلك.
- كل الكتابة في معاملة واحدة: إن فشل أي جزء لا يتغير شيء.

## التوافق

- الملفات من إصدارات أقدم من قاعدة البيانات (مثل v4 قبل جداول التقدم والتصاميم) تُقرأ، والجداول الناقصة تُعامَل كفارغة.
- تُرفع `formatVersion` فقط عند تغيير لا تستطيع الإصدارات الأقدم فهمه.
