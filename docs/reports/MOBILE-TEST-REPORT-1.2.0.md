# تقرير اختبار الجوال — IBRAHI8M EDU STUDIO 1.2.0

## طريقة الاختبار

- **محاكاة Chromium بمقاسات الأجهزة**، وليست أجهزة حقيقية:
  - Pixel 7: ‏412×915، لمس.
  - iPhone SE: ‏320×568، لمس.
  - iPad mini: ‏768×1024.
- **لم يُختبر شيء على جوال حقيقي ولا على Safari.**
- نسخة الجوال تطبيق ويب يُثبَّت من المتصفح (PWA)، **وليست تطبيقًا أصليًا**. لم تُبنَ نسخة APK أو AAB أو iOS: أدوات Android محجوبة عن هذه البيئة، وiOS يحتاج macOS.

## التثبيت على الجوال

1. افتح الرابط https://ibrahi8m.github.io/edu-studio/ (في Safari على iPhone)، وانتظر «جاهز للعمل دون إنترنت».
2. ثبّته:
   - **Android:** ⋮ ← «تثبيت التطبيق».
   - **iPhone:** المشاركة ← «إضافة إلى الشاشة الرئيسية».
3. إن كنت قد ثبّته سابقًا: افتحه مع الإنترنت، واضغط «تحديث الآن» عند ظهوره.

**على iPhone:** الموسيقى تتوقف إذا كان مفتاح الصامت مفعّلًا في بعض إصدارات iOS (سلوك Safari). هذا لم يُختبر هنا.
