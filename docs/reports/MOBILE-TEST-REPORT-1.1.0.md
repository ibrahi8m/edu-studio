# تقرير اختبار الجوال — IBRAHI8M EDU STUDIO 1.1.0

## ما الذي اختُبر، وكيف

- **الجوال المختبر محاكاة، لا جهاز حقيقي:** Chromium من Playwright بمقاسات الأجهزة وخصائصها، أي حجم الشاشة وكثافة البكسل واللمس ووكيل المستخدم.
  - **Pixel 7:** ‏412×915، لمس.
  - **iPhone SE:** ‏375×667، أصغر شاشة مختبرة. بمحرك Chromium لا Safari.
  - **iPad mini:** ‏768×1024، لوحي.
- **لم يُختبر على أي جوال حقيقي، ولا على Safari الحقيقي.**
- **نسخة الجوال تطبيق ويب تقدمي (PWA)** يُفتح من الرابط ويُثبَّت من المتصفح، وليس تطبيق Android أو iOS أصليًا.

## طريقة التثبيت على الجوال اليوم (PWA)

1. افتح الرابط https://ibrahi8m.github.io/edu-studio/ (في Safari على iPhone).
2. انتظر «جاهز للعمل دون إنترنت» في لوحة التحكم.
3. **Android:** ⋮ ← «تثبيت التطبيق». **iPhone:** المشاركة ← «إضافة إلى الشاشة الرئيسية».
4. فعّل وضع الطيران، وافتح التطبيق من أيقونته للتأكد.

## لبناء تطبيق Android أصلي لاحقًا

على جهاز فيه Android Studio:

1. أضف Capacitor إلى المشروع: `npm i @capacitor/core @capacitor/cli @capacitor/android`، ثم `npx cap init`. مجلد الويب هو `dist`.
2. نفّذ `npm run build`، ثم `npx cap add android`، ثم `npx cap open android`.
3. ابنِ APK أو AAB من Android Studio، ووقّعه بمفتاحك.
