## iOS: ما ينقص لتثبيت التطبيق على iPhone

**موجود وجاهز في المشروع:**

- المعرّف `app.ibrahi8m.edustudio`، والإصدار 1.6.0.
- iOS 13 وما بعده، على iPhone وiPad.
- الأيقونة وشاشة البداية.
- مفتاح «لا تشفير خاص» (`ITSAppUsesNonExemptEncryption = NO`)، فلا يُسأل عنه عند الرفع.
- الدخول السحابي ممكن من داخل التطبيق: عنوان Supabase مسموح في سياسة الأمان.

**ما ينقص، بالترتيب:**

1. **جهاز Mac** عليه:
   - **Xcode 26 أو أحدث.** منذ 28 أبريل 2026 يشترط App Store Connect البناء بـ Xcode 26 وiOS 26 SDK.
   - **CocoaPods:** `sudo gem install cocoapods`.
   - **Node.js 18 أو أحدث.**
2. **البناء:**
   ```bash
   npm ci && npm run build
   cd ios && npm ci
   npx cap sync ios
   npx cap open ios
   ```
   - `npx cap sync ios` ينسخ نسخة الويب ويشغّل `pod install`.
   - `npx cap open ios` يفتح المشروع في Xcode.
3. **التوقيع** (Xcode ← Signing & Capabilities ← Team):
   - **للتجربة على iPhone الخاص بك فقط:** يكفي Apple ID مجاني (Personal Team).
     - **حدود Apple:** صلاحية التثبيت 7 أيام ثم تعيد التثبيت، و3 أجهزة على الأكثر.
   - **لـ TestFlight أو App Store:** عضوية Apple Developer Program، بـ **99 دولارًا سنويًا**.
4. **النشر:**
   - Product ← Archive، ثم Distribute ← App Store Connect.
   - ثم TestFlight للتجربة، أو المراجعة للنشر.
5. **مخاطر يجب التحقق منها على الـ Mac:**
   - **Capacitor 6 مع Xcode 26:** لم يُجرَّب. إن ظهرت أخطاء بناء، فالحل الترقية إلى Capacitor 8، وهي تشترط Xcode 26 وiOS 15 وNode 22.
   - **التنزيلات داخل التطبيق لا تعمل في WebView على iOS:** حفظ TXT وPNG والنسخ الاحتياطية.
     - **الحل:** إضافتا `@capacitor/filesystem` و`@capacitor/share` وربطهما. لم يُنفَّذ.
   - **مراجعة Apple:** قد ترفض تطبيقًا يراه «موقع ويب مغلّفًا» (البند 4.2). عمل التطبيق دون اتصال يساعد، لكنه لا يضمن القبول.
6. **بديل يعمل الآن دون Mac:**
   - افتح https://ibrahi8m.github.io/edu-studio/ في Safari.
   - ثم «مشاركة» ← «إضافة إلى الشاشة الرئيسية».
